Installing Fedora Workstation: Quick Guide

This guide provides a straightforward summary of the official Fedora documentation to get Fedora Workstation running on your computer.

Important: Installing a new operating system can result in data loss. Ensure you back up all crucial files before proceeding.

Step 1: Download Fedora Media Writer

Go to the official Fedora website and download the Fedora Media Writer tool for your current operating system (Windows, macOS, or Linux). This utility safely downloads the latest Fedora Workstation ISO and writes it directly to a USB drive.

Step 2: Create the Bootable USB

Insert a blank USB flash drive (minimum 8GB capacity) into your PC. Open Fedora Media Writer, select Fedora Workstation, and choose your target USB drive. Click Write to Disk and wait for the verification process to complete.

Step 3: Boot from the USB Drive

Shut down your computer completely. Turn it back on while repeatedly pressing your motherboard's boot menu key (common keys include F12, F11, F8, or Esc). Select your USB drive from the hardware list to launch the Fedora live environment.

Step 4: Run the Installer

Once the desktop loads, click the Install to Hard Drive icon. Select your language and keyboard layout configurations on the introductory screen.

Step 5: Partition and Install

Click on Installation Destination. Select your main storage drive. You can choose automatic partitioning to let the system automatically manage system space, or manually configure your mount points. Click Begin Installation to apply configurations and extract the filesystem target.
